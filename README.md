# 用于替换Windows里的微软雅黑

汉字提取的版本为 **19.0d5e2**， 英数 **SF Pro Text** 版本 **22.0d4e4**、**SF Pro Display** 版本 **22.0d4e4**。

## 用法

高级启动 **xcopy c:\fonts c:\windows\fonts**
